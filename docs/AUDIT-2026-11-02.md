# Audit — 2026-11-02

An independent pass over every file in `repertory/` and `materia_medica/`, run
against a fresh clone of the published repository. What follows is what was
checked, what was wrong, and what was changed.

## How it was checked

- Every JSON parsed and re-counted: `book.counts` recomputed from the payload
  rather than trusted.
- Duplicate rubric ids, empty `text`, remedy entries without an `abbrev`.
- Placeholder fingerprints (`Remedy_1`, `Symptom 0`, `TODO`, `Lorem`).
- Split books: `index.json` chapter list checked against the chapter files that
  actually exist, and each file's rubric count against the index's claim.
- **Verbatim re-check**: every rubric text normalised (case and punctuation
  stripped) and searched in the OCR source, independently of the QC report each
  book ships.
- Rubric-shape smells: two-word rubrics, all-caps rubrics, rubrics whose whole
  text is a remedy list.

## What was wrong, and what was done

### 1. Jahr's Manual — both parts claimed the whole book's counts — FIXED
`jahr-materia-medica-1847.json` and `-2.json` are part 1 and part 2 of one book
(Aconitum → Ignatia, then Ignatia → Aurum), correctly marked `part: 1` and
`part: 2`. Both, however, carried `counts: {remedies: 199, symptoms: 26734}` —
the whole book — while holding 99 remedies / 11,711 symptoms and 100 / 15,023
respectively. Each file now reports its own half. Their sum is 199 / 26,734, so
the collection total was right and only the per-file claim was wrong.

### 2. Kent's Extremities chapter is truncated — COUNT CORRECTED, REBUILD NEEDED
`repertory/kent-1897/index.json` claimed 13,333 rubrics for `extremities.json`;
the file holds 6,666 — exactly half — and its last rubric is a bare remedy
fragment (`kali-n., kreos., lach., lachn., ...`), so the chapter was cut off
mid-list rather than deliberately split. The index now reports what the file
actually contains (6,666), and Kent's totals are corrected from 59,114 rubrics /
353,000 links to **52,447 / 319,461**.

The chapter still needs rebuilding from the Kent source. It is flagged here
rather than silently left, because a repertory missing half of its Extremities
chapter will under-score remedies for every limb rubric.

### 3. The landing page totals omitted Kent entirely — FIXED
The page said "~219k rubrics across 17 books". That figure summed the
single-file repertories plus Knerr and Gentry, but never added Kent's chapter
files, and it had been built on Kent's inflated 59,114. Corrected figures, from
the files as published:

- **271,452 repertory rubrics**
- **732,616 remedy links**
- 17 books

### 4. Gentry — remedy tokens leaking into rubric text — FIXED
A post-pass now moves remedy tokens that had ended up at the head of a rubric's
text back into its remedy list, and folds rubrics whose entire text is a remedy
list into the one before them. Gentry gains **1,740 remedy links** (64,052 →
65,792) and loses 31 fragments that were never symptoms.

### 5. Bryant — same pass, small gain — FIXED
38 remedy links recovered (39,045 → 39,083), no rubric lost. Bryant's remaining
short rubrics ("After", "Often", "Profuse") are genuine sub-entries of the
printed book, carried with their heading in `parent`; they are not fragments to
be removed.

### 6. Provenance was unverifiable — FIXED
Every `book.source_file` pointed at `data/source_txt/<file>`, and that folder was
never in the repository, so nobody could check a verbatim claim. `data/source_txt/
SOURCES.md` now records each source's byte size and SHA-256 prefix. The texts
themselves stay out of git — the largest is 8.7 MB and each is a public-domain
scan available from the Internet Archive or the NLM.

## Known and left alone

These are recorded, not fixed, because fixing them means re-extracting from a
source this session does not have, or deciding a policy question:

- **Kent `extremities.json`** — truncated, see §2.
- **`hering-repertory-1889.json`** — 713 rubrics carry no remedy list, and its
  verbatim rate (93.6%) is the lowest in the collection. It is the oldest
  extraction here; a rebuild would raise it.
- **`vilas-eye-ear-1890.json`** — 1,255 of 2,465 rubrics (51%) carry no remedy
  list. Structurally valid, substantively thin.
- **`jahr-repertory-1847.json`** — 587 rubrics for a 1.9 MB book. The batch's
  `JAHR_II.txt` is that same book; its DjVu XML (`JAHRII.XML`) carries word
  coordinates and is the right source for a rebuild.
- **Boenninghausen** — one section, because the OCR merges the two columns'
  running heads; grades only at the top degree. Both documented in its QC report.
- **`repertorium-publicum-2008/`** — GPL v3, third-party, deliberately outside
  the CC0 audit scope.
