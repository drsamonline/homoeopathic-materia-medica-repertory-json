The book object

Shared by both shapes.

fieldtypenotes
idstringslug, e.g. kent-repertory-1897
titlestringfull title
authorstringauthor(s)
yearintegeryear of the edition used
publisherstringwhere known, else ""
source_filestringthe OCR text file it was built from
countsobject{ sections, rubrics, remedy_links } or { remedies, symptoms }

repertory fields

fieldtyperule
sections[].titlestringa chapter (e.g. Mind, Stomach), or General when the source has no chapter structure
rubrics[].textstringthe symptom string, verbatim from the source
rubrics[].parentstring|nullfor sub-rubrics, the heading this entry refines; null for a top-level rubric
remedies[].abbrevstringthe remedy exactly as printed
remedies[].gradeinteger|null1–3 only if the source prints a grade, otherwise null — never defaulted
remedies[].namestring|nullcanonical remedy name, resolved where possible, else null
remedies[].polaritystringprinted polarity marker (e.g. +)
rubrics[].notestring|nullverbatim prose attached to a rubric (Jahr Part II), else null
remedy_indexobjectevery printed remedy token → { name, resolved }

materia_medica fields

fieldtyperule
remedies[].namestringthe remedy as printed (may be OCR-damaged in some books)
remedies[].abbrevstringprinted abbreviation
remedies[].canonical_namestring|nullbest-effort resolved name, else null
symptoms[].chapterstringthe labelled group the symptom belongs to (e.g. Stools, Aggravation), or General
symptoms[].textstringthe symptom string, verbatim
symptoms[].gradeinteger|nullonly if printed, else null

Three rules of the data

1. Verbatim — every text is copied from the source, not rewritten.  2. No invention — unknown values are null; grades are never assumed.  3. Validation — each file passes schema validation with zero errors and reports a verbatim-fidelity rate in its QC report.

// get started

Download & fetch

No build step and no install. Read any book straight from a raw URL or a jsDelivr CDN URL. Files are compact JSON and parse identically to pretty-printed.

Fetch a whole repertory (Python)

fetch.pypython
import json, urllib.request

URL = "https://raw.githubusercontent.com/drsamonline/" \
      "homoeopathic-materia-medica-repertory-json/main/" \
      "repertory/kent-1897/index.json"

rep = json.load(urllib.request.urlopen(URL))
for sec in rep["sections"]:
    for r in sec["rubrics"]:
        if any(x["abbrev"] == "Acon" for x in r["remedies"]):
            print(sec["title"], ">", r["text"])

Fetch in the browser / Node

app.jsjavascript
const base = "https://cdn.jsdelivr.net/gh/drsamonline/" +
             "homoeopathic-materia-medica-repertory-json@main/";

const rep = await fetch(base + "repertory/kent-1897/mind.json")
  .then(r => r.json());

const mind = rep.section;
console.log(mind.rubrics.length, "mind rubrics");

Questions

Q. What exactly is in this dataset? ▸
A curated collection of 13 public-domain homoeopathic Materia Medica and Repertory classics (1840–1906), extracted from their scanned page images into structured JSON ready for apps, search tools, study aids and AI projects. Eleven are repertories (rubric → remedies) and two are materia medicas (remedy → symptoms).
Q. Is the text verified? ▸
This is honest, verbatim OCR data, not hand-verified text. Every rubric/symptom string is verbatim from the source scan, and each book reports a verbatim-fidelity rate. Some books carry OCR fragments and garbled remedy abbreviations (notably Vilas, Lippe, Clarke, Pulford, Bryant); Bell’s remedy names are OCR-mangled (partly auto-resolved). Verify against the original text before clinical use.
Q. What does "grade": null mean? ▸
A grade is an integer 1–3 only if the source prints a grade, otherwise it is null. Grades are never defaulted or assumed. The same no-invention rule applies to every unknown value — it is null, never a guess.
Q. Why is Kent split into chapters? ▸
Kent is provided split by chapter in repertory/kent-1897/ — 34 chapter files plus index.json — so an app can load one chapter at a time. Its single 21 MB file exceeds GitHub’s per-file upload limit, so it ships as parts (e.g. extremities.json + extremities-2.json). Concatenate the parts to rebuild the full file.
Q. Can I use this commercially? ▸
Yes. The data is released under CC0 1.0 Universal — a public domain dedication — free to use, modify and redistribute, including commercially. Please still credit the book authors and the JSON compiler (Dr Sohil Momin) wherever the data is used.
Q. How was the data produced? ▸
The extraction is fully reproducible. pipeline/omm_pipeline.py classifies a source text, applies the right grammar parser, validates the output and reports a verbatim-fidelity rate. skill/omm-json-builder/ packages the same pipeline as an agent skill.
Q. I found a bad OCR token — can I fix it? ▸
Please do. Open an issue describing the book, the rubric and the correct reading, or open a pull request with the correction. See CONTRIBUTING.md for the rules of the data (verbatim, no invention).
Q. Is this medical advice? ▸
No. These are historical texts for study and software. They are not medical advice — always consult a qualified practitioner.
